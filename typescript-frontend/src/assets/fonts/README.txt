Self-hosted Latin variable fonts from Google Fonts:

Cormorant Garamond: Roman and italic, used at weights 500-600.
https://fonts.google.com/specimen/Cormorant+Garamond
License: cormorant-garamond-OFL.txt

DM Sans: Roman, used at weights 400-700.
https://fonts.google.com/specimen/DM+Sans
License: dm-sans-OFL.txt

These subsets include Norwegian letters. Other glyphs use the CSS fallback
families. Font files are served with the application, not from Google at runtime.
